# PHL Audio Menu Dylib Project
Thự viện `.dylib` phát nhạc trực tuyến từ GitHub cho iOS (Esign), chống debug / anti-crack, không ảnh hưởng cảm ứng game.

## Hướng dẫn build file .dylib chuẩn Mach-O (Hiện mục "Sửa đổi sự phụ thuộc" trong Esign):
1. Đẩy toàn bộ các file trong thư mục này lên một GitHub Repository mới ở chế độ **Public**.
2. Vào tab **Actions** trên GitHub, bạn sẽ thấy tiến trình đang tự động biên dịch `amthanh.dylib`.
3. Khi hoàn tất, tải artifact `amthanh-dylib` về. File `.dylib` tải về là Mach-O binary chính thống tương thích 100% với ESign.
